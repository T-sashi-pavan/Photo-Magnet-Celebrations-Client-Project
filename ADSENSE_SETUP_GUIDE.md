# Google AdSense Integration Guide

## Your AdSense Setup Status

### ✅ Ready for AdSense:
- Website is live
- Original content (product pages)
- Contact, Privacy, Terms pages (REQUIRED by AdSense)
- Professional design
- Mobile responsive

## What You Need to Do:

### 1. Sign Up for Google AdSense
- URL: https://www.google.com/adsense/start/
- Use the email: photomagnetcelebrations@gmail.com
- Provide business details from Contact page

### 2. Get Your Publisher ID
After approval, you'll get a Publisher ID like: `ca-pub-XXXXXXXXXXXXXXXX`

### 3. Create Ad Units
In AdSense dashboard, create these ad units:
- **Header Banner** (728x90 for desktop, 320x50 for mobile)
- **Sidebar Ad** (300x250)
- **Footer Ad** (728x90)

### 4. Copy Ad Codes
Copy the JavaScript/HTML code for each ad unit.

### 5. Send to Developer
Share:
- Publisher ID
- Ad unit codes
- Where you want ads displayed

## Ad Placement Recommendations:

✅ **Good locations:**
- After product description
- Sidebar (if we add one)
- Between customer reviews
- Footer area

❌ **Avoid placing ads on:**
- Checkout page (against AdSense policy)
- Payment pages
- Near contact forms
